# Phase 7A frozen feasibility protocol

Use dataset-v1, checksum `18d58ee83e05e11164876b68feb0cebacba9755eb3395d6f0a8097cb2eb652ed`, with the original 40/7/7/7 train/validation/test/stress groups. Only the exact 30-feature order in the manifest is inference input. IDs, family, current truth, future outcomes and heuristic decisions are evaluation metadata only.

Two candidates: median imputation (`keep_empty_features=True`), StandardScaler, L2 logistic regression C=1, lbfgs, tolerance 1e-6, max_iter=2000, with class_weight=None or balanced. No feature selection, oversampling, model-family search or probability recalibration. Training uses one numerical-library thread. All preprocessing and balanced weights are fitted independently inside four StratifiedGroupKFold folds, shuffled with seed 20261117, exclusively on training groups.

Choose each candidate's threshold from a fixed 41-point geometric grid from 0.001 to 0.95 plus 1.0 using training out-of-fold F2. Tie-break by fewer false alarm episodes/hour, higher pre-event incident recall, longer median warning lead, then higher threshold. Choose the candidate with the same objective; exact ties prefer unweighted. Fit both candidates on all training data and save their parameters, thresholds and a selection checksum before evaluating validation/test/stress. No fitting or selection uses those partitions. No repeated held-out tuning.

Baselines: always negative; and a forward-only sensor TTC heuristic, warning when current measured lead TTC <=4.5 s (3 s future horizon +1.5 s near-miss boundary), or lead clearance <2 m, for ego speed >2 m/s. Clearance is max(0, lead_lon_m−3.9), and closing is −lead_v_lon_mps >0.1. Its continuous score is 1/(1+TTC), with score 1 for a sub-2 m gap. This is an offline, constant-velocity forward baseline, not the deployed unified safety actions. No existing global min-TTC (which can include rear threats), rule decisions, or simulator geometry enters the learner.

Temporal incidents follow the Phase 6D definition: physical-truth near-miss positives clustered with <=1 s between positives, stopping at the first overlap proxy. Pre-event detection requires a warning in [onset−3 s,onset), outside an already developing near miss and after the previous incident's end. Report unavailable pre-event windows rather than count them as misses or fabricate data. Report warnings during developing near misses separately. Lead time is the earliest eligible warning sample within the 3 s window, capped by that horizon, not an assertion about first alarm onset or actual impact.

False alarm episodes are consecutive warning samples on the valid 200 ms grid whose entire episode has target=0. Exposure is the sum of valid sample intervals, not wall time or gaps. Also report frame FPR, false-positive frames/hour and warning duty cycle to reveal sustained alarms. Every family is evaluated separately. Equal-width score bins assess calibration; outputs remain uncalibrated risk scores. Group bootstrap intervals use 1,000 resamples, seed 20261117; zero-denominator resamples are excluded and counted. With only two positive validation/test groups, intervals remain descriptive and generalization weak.

JSON artifacts contain coefficients, intercept, median/scaler parameters, exact feature order, threshold, dataset and source checksums, versions and training settings. Verify every exported score against scikit-learn on all retained samples. Measure standard-library batch-1 inference on Mac; no Pi benchmark/deployment is authorized. The standalone predictor validates artifacts and inputs and reports failure without supplying a safety action. Future integration is shadow-only and must isolate failures from the authoritative pipeline.
